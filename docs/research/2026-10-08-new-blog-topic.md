# Research brief — Claude Haiku 5.5's 100k-token pricing threshold

**Researched:** 2026-10-08. **One proposed topic:** How to budget Haiku 5.5 subagent prompts near 100,000 tokens. **Suggested slug:** `/research/haiku-5-5-100k-prompt-price-threshold`.

## Why now; distinct editorial angle

Anthropic released Claude Haiku 5.5 on **2026-10-07**. It markets the model for high-volume, cost-sensitive work and subagents, but its published prices change when a prompt exceeds 100,000 tokens. The useful FinOps story is a **preflight prompt budget**: recount real requests with the new tokenizer, watch the distribution near 100k, and decide whether to trim, compact, or route long prompts after testing quality and total task cost. This is a decision guide, not a launch recap or a generic model-price comparison. [Announcement](https://www.anthropic.com/claude-haiku-5-5); [Haiku 5.5 model overview](https://platform.claude.com/docs/en/models/haiku-5-5/overview); [pricing documentation](https://platform.claude.com/docs/en/about-claude/pricing).

## Verified claims for the eventual article

- **Launch and availability:** Anthropic dates the announcement **2026-10-07**; its model overview lists that release date and model ID `claude-haiku-5-5`. It has a 1M-token context window, but the low advertised rate is conditional on prompt length. [Announcement](https://www.anthropic.com/claude-haiku-5-5); [model overview](https://platform.claude.com/docs/en/models/haiku-5-5/overview).
- **Exact Claude API list rates, USD per million tokens:** for prompts **up to 100,000 tokens**, input $0.10, output $0.50, 5-minute cache write $0.125, 1-hour cache write $0.20, cache read $0.01; for prompts **over 100,000**, respectively $0.50, $2.50, $0.625, $1.00, and $0.05. Each published rate is 5× across the boundary. Anthropic says a prompt over 100k pays the higher prices; describe this as prompt-length pricing, not a charge on only the excess tokens. [Model overview](https://platform.claude.com/docs/en/models/haiku-5-5/overview); [pricing documentation](https://platform.claude.com/docs/en/about-claude/pricing).
- **Migration changes the measured denominator:** Anthropic says the same input text produces approximately **30% more tokens** on Haiku 5.5 than on Haiku 4.5, depending on content. Recount prompts using the *target model* before applying a 100k guardrail; do not reuse Haiku 4.5 counts. Anthropic's separate “around 75% less to run” claim is its average estimate, not a guaranteed reduction for every task. [What's new](https://platform.claude.com/docs/en/models/haiku-5-5/whats-new-haiku-5-5); [announcement, pricing footnote](https://www.anthropic.com/claude-haiku-5-5).
- **How to verify the budget:** Anthropic's token-counting endpoint estimates a request before sending it; its estimate may differ slightly from actual input usage, and some server tools or URL/file blocks are unsupported. Log actual response usage and realized cost after the call. Cached prefixes still occupy context, so caching does not make long prompts short. [Token counting](https://platform.claude.com/docs/en/build-with-claude/token-counting); [context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows).

## Caveats and suggested treatment

Use the official Claude API rates as the worked example; verify the buyer's platform, contract, batch/region modifiers, and live rate card before quoting an invoice. Do not promise a fivefold *bill* increase or a particular saving: output length, cache hits, thinking, retries, and task success change the total. Adaptive thinking is on by default for Haiku 5.5, and thinking tokens count toward `max_tokens`; evaluate the actual workload at its chosen effort level. Anthropic's 50% Batch API discount applies to input and output, but asynchronous processing may change the product fit. [Model overview](https://platform.claude.com/docs/en/models/haiku-5-5/overview); [pricing documentation](https://platform.claude.com/docs/en/about-claude/pricing); [batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing).

**Editorial payoff:** Show a small prompt-length histogram around 100k, then a before/after *measured* cost-per-successful-task comparison for trimming repeated context or routing the long tail. The numeric rates above are verified in Anthropic's live, undated pricing docs as consulted **2026-10-08**; recheck before publication.
